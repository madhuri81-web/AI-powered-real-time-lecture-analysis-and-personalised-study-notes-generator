## 📌 Overview

Students often find it difficult to take detailed notes while simultaneously listening to a lecture.

This project uses Artificial Intelligence to analyze lecture content and transform it into:

- 📝 Structured study notes
- 🔑 Important key points
- 📚 Topic-wise summaries
- ❓ Questions for revision
- 🧠 Personalised learning material

The goal is to make studying faster, easier, and more effective.

## ✨ Features

### 🎙️ Real-Time Lecture Analysis
Processes lecture content and identifies important information.

### 📝 Automatic Note Generation
Converts lecture content into clear and structured study notes.

### 🔑 Key Point Extraction
Identifies important concepts, definitions, and points from the lecture.

### 📚 Personalised Notes
Generates notes based on the student's learning requirements.

### ❓ Question Generation
Creates questions from lecture content to help students revise.

### 🤖 AI-Powered Learning
Uses Generative AI to understand lecture content and create useful educational material.
